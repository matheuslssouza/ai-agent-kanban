# Papéis canônicos

Este diretório contém o corpo canônico dos papéis especializados do projeto.

Adaptadores opcionais podem ser gerados a partir daqui:

- Claude Code: `.claude/agents/`
- Cursor: `.cursor/rules/`
- Antigravity: `.agents/rules/`
- Codex: `.codex/agents/`, somente quando o projeto usar delegação específica

Não crie um papel apenas para representar uma persona. Crie-o quando houver uma
fronteira técnica real, uma regra que muda por área ou uma operação de risco que
merece veto explícito.
